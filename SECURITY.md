# Politique de sécurité

## Versions prises en charge

Seule la dernière version publiée sur la page
[Releases](https://github.com/Sietch-Tabr/tamponne/releases) reçoit des
correctifs.

## Signaler une vulnérabilité

Ne pas ouvrir de ticket public. Utiliser le signalement privé de GitHub :
onglet **Security** du dépôt, puis **Report a vulnerability**.

Indiquer la version de Tamponné, le système, et les étapes pour reproduire le
problème. Ne joindre ni données personnelles ni contenu de candidature.
